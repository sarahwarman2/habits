    Sync across devices

    Off. Your habits stay on this device only.

    Set up sync

    Your habits are saved in a file called habits.json inside a private GitHub repository that you own. Use a token that can only reach that one repository. The token is stored on this device and is never included in backups.

    Back up and restore

    A backup is a safety copy you keep yourself. Restoring replaces everything on this device.
